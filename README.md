# D-Tector for Apple Watch

D-Tector เวอร์ชัน Native สำหรับ Apple Watch พัฒนาด้วย Swift และ SwiftUI รองรับ watchOS 10 ขึ้นไป

Repository นี้เปิดไว้เพื่อแบ่งปัน Source Code ให้ผู้ที่สนใจได้นำไปศึกษา ทดลอง แก้ไขบั๊ก และพัฒนาต่อยอด

## Original project and credits

โปรเจกต์นี้พัฒนาต่อยอดมาจาก [D-Tector-v2](https://github.com/kaisadilla/D-Tector-v2) โดย **kaisadilla** ซึ่งเป็นต้นฉบับที่สร้างด้วย Unity สำหรับเล่นบนคอมพิวเตอร์

ขอขอบคุณ **kaisadilla** สำหรับตัวเกม ระบบ ข้อมูล และทรัพยากรที่เป็นพื้นฐานสำคัญของเวอร์ชันนี้ หาก Fork, ดัดแปลง หรือเผยแพร่โปรเจกต์นี้ต่อ กรุณาคงชื่อผู้สร้างและลิงก์ของโปรเจกต์ต้นฉบับไว้ด้วย

## About this Apple Watch port

เวอร์ชันนี้นำโครงสร้างเกมและข้อมูลจาก Unity เดิมมาศึกษา แล้วเขียนส่วนแอปใหม่ให้ทำงานแบบ Native บน watchOS โดย:

- เขียนระบบแอปใหม่ด้วย Swift และ SwiftUI
- จัดเตรียมข้อมูลตัวละคร แผนที่ Sprite และเสียงสำหรับ watchOS
- ปรับหน้าจอและการควบคุมให้เหมาะกับ Apple Watch
- เพิ่มการแตะซ้าย–กลาง–ขวา การแตะค้าง และการเขย่าข้อมือ
- เพิ่มระบบบันทึกเกมและโปรเจกต์ Xcode ที่พร้อม Build

ผู้ดาวน์โหลดไม่ต้องติดตั้ง Unity และไม่ต้องแปลงโปรเจกต์ใหม่ สามารถเปิดโปรเจกต์ด้วย Xcode แล้วพัฒนาส่วนของ watchOS ต่อได้เลย

## Requirements

- Mac และ Xcode เวอร์ชันล่าสุด
- Apple Watch ที่ใช้ watchOS 10 ขึ้นไปและจับคู่กับ iPhone แล้ว
- Apple Account สำหรับเซ็นแอป

## Installation

1. ดาวน์โหลดหรือ Clone repository นี้
2. เปิด `AppleWatch/DTectorWatch.xcodeproj` ด้วย Xcode
3. ลงชื่อเข้าใช้ Apple Account ที่ **Xcode > Settings > Accounts**
4. เปิด **Signing & Capabilities** ของ `DTectorWatch` และ `DTectorComplication`
5. เลือก Team ของตัวเอง เปิด **Automatically manage signing** และเปลี่ยน Bundle Identifier ทั้งสองรายการให้ไม่ซ้ำ
6. เลือก Apple Watch จากด้านบนของ Xcode แล้วกด **Run** หรือ `Command + R`

ไม่ต้องติดตั้ง Unity, Node.js หรือ XcodeGen

## Controls

- แตะซ้ายหรือขวาเพื่อเลื่อนเมนู
- แตะกลางจอเพื่อยืนยันหรือเดิน
- เขย่าข้อมือเพื่อเดิน
- แตะค้างประมาณครึ่งวินาทีเพื่อย้อนกลับ

## Notes

- บัญชี Apple แบบฟรีอาจต้องนำแอปกลับมาติดตั้งผ่าน Xcode ใหม่ทุก 7 วัน
- โปรเจกต์นี้เป็นแฟนโปรเจกต์ที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้องหรือได้รับการรับรองจากเจ้าของลิขสิทธิ์
- แบ่งปันเพื่อการศึกษา ทดลอง และพัฒนาต่อยอดโดยไม่มีค่าใช้จ่าย ห้ามนำไปจำหน่าย
- สิทธิ์ในชื่อ ตัวละคร ภาพ เสียง และทรัพยากรต่าง ๆ เป็นของเจ้าของสิทธิ์ที่เกี่ยวข้อง
